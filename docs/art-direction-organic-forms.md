# 《孤岛余生：风暴物语》拟物化造型规格

版本：1.0｜适用：Three.js / 微信小游戏｜目标：消除粗方块轮廓，不把卡通画面改成写实滤镜。

## 核心判断

做“清爽、可信、可触摸的手工岛屿”，保留明快的卡通比例与颜色。物体像真实物件的简化模型：外轮廓、体积转折、连接关系和接触方式可信；不追求照片级材质、脏污、镜头颗粒、泛光或锐化。先改几何，再改材质；如果灰模缩略图仍像方块，材质工作不得算通过。

## 造型硬规则

- 主轮廓不得由未处理的 `BoxGeometry`、立方块或相同尺寸堆叠组成。木屋、船、码头、田垄各自必须有完整外形、厚度、转折与连接结构。
- 方形木料可以作为次级构件，但需倒圆边、略有尺寸差异，并由梁、榫接、绑绳、檐口或支脚解释其结构用途；禁止“给方块加噪声”冒充拟物化。
- 主要外形用曲线截面、渐变截面、圆角轮廓或叶片/板片网格建立。倒角只负责接光，不可成为唯一造型改动。避免完美球体、圆柱和圆锥的简单堆叠。
- 接缝和分件应有真实搭接、包边、缝隙或紧固件；物体必须落地、入土、系泊或由支架支撑，不得漂浮、穿插或仅靠贴图假装厚度。
- 有机物保留轻微不对称：叶片长短、倾角和弯曲不同；海岸线与浪花断续、疏密变化；果蔬与珊瑚不可复制成同尺寸同朝向的球串。
- 卡通低多边形不等于方块：转折可以清晰，但曲面法线与轮廓要连续；在游戏镜头缩到 50% 时仍能识别物种与功能。

## 按类别的目标形状

|类别|必须读到的形体|拒收特征|
|---|---|---|
|棕榈与植被|树干由粗至细、自然倾斜并略弯；冠部有扇状叶轴，叶片由中央叶脉伸出成对小叶，末端尖细下垂；椰果围绕树冠成簇。常见棕榈源网格目标 1,200–2,500 三角面/棵|竖直圆柱树干、平板状整片叶、叶子呈方片/十字、重复叶片完全同形；超预算先减小叶片采样，不减到失去羽状剪影|
|海滩与浪花|岛岸是连续起伏的沙坡剖面；干湿沙用宽而不规则的过渡带区分；泡沫贴合实际岸线，形成细碎、断续、有厚薄变化的白边|方形沙地贴片、硬直边界、等宽闭合白圈、与岸线错位的独立泡沫球|
|海水|浅滩颜色由水深平滑过渡；波纹使用宽窄变化的细长曲带与局部高光，浪尖低矮、分段、沿岸走向一致|均匀蓝色平面、重复同心圆、厚白管、整片高对比噪点|
|小屋|明确的坡屋顶、檐口厚度、可见支撑/檩条、门窗凹进墙面；墙体与屋面材质、厚度区分；屋顶轮廓优先于贴图纹理|立方体房身叠一个方锥顶、无檐薄片、窗户浮贴墙面、仅靠木纹纹理表示墙板|
|小船与码头|船壳有尖/圆润船首、收窄船底与高于水线的船舷；甲板、座板、舵/桨和系缆点可辨；码头由独立圆角木板、横梁、桩柱与绳结组成|平底长方盒船、木板方砖拼地、无支撑悬空甲板、方柱齐刷刷高出平台|
|田垄与作物|土垄是低矮的椭圆脊与真实沟槽；秧苗由主茎、不同方向叶柄和叶片构成；每个作物阶段有轮廓变化，果实长在枝叶内|扁圆底座加三根圆柱、相同绿球代替所有作物、用颜色变化伪装成熟阶段|
|鱼与海产|鱼身为头宽中段饱满、尾柄收窄的纺锤体；胸鳍、背鳍、尾鳍和眼睛与主体相连且有薄厚；贝壳有开合边、扇脉和厚壳口|球形鱼身、矩形鱼尾、浮在鱼身外的三角片、没有壳口厚度的扁圆贝|
|工具与家具|手柄有握持粗细变化、端头符合功能；布、绳、木、金属各自以结构表现连接；家具腿与台面有承托关系|长方体+圆柱的默认拼装、浮空握把、厚实方块状金属件、不可读的装饰件|

## 材质与灯光边界

- 使用柔和、受控的手绘色块、粗糙度分层和小范围烘焙 AO；AO 只强调接触缝，不染黑大面积表面。
- 颜色变化服务于材质分区和形体转折，不以全屏色调 LUT、过饱和、强 bloom、景深、胶片颗粒或写实污渍掩盖几何问题。
- 高光宽而柔，金属范围小；沙、木、叶、石、鱼鳞的粗糙度与反光有区别，但仍保持一致的卡通渲染语言。
- 贴图负责细节，不负责轮廓。缩略图/无贴图灰模仍应先看得出“这是什么、如何组成、如何接触”。

## 资产与验收

- 建模以 Blender GLB 与现有共享图集管线为准；重复植被、木板与鱼群优先实例化/共享网格，共用材质，不为微表面细节新增独立纹理图。
- 每类先改一个代表物：棕榈、屋顶/墙体、船壳、岸线泡沫、田垄、鱼。代表物灰模通过轮廓审查后再批量推广。
- 棕榈专项通过项：连续树干而非分段锥体；冠幅角度/长短不等且保留一至两个自然空隙；叶轴到小叶连接清楚；单源 1,200–2,500 三角面，8 个场景实例仍复用同一实例网格/绘制批次。
- 同一生产镜头同时检查：近景细节、正常游戏距离、50% 缩略图、纯灰模、纯轮廓剪影。检查接地/接水线、结构支撑、穿插和遮挡；任何主形体仍呈“几个盒子拼起来”即退回重做。
- 每次只替换一个类别并比较旧/新截图；目标设备帧率、包体、Draw Call 不得因小装饰显著回退。保留现有实例化、压缩/图集预算。
- 当前本规格不授权付费生成服务，也不代表每项资产已经按规格完成；导出后须在正式游戏镜头复核，并单独通过微信开发者工具与真机门槛。

## 迭代顺序

1. 海滩横截面、海岸轮廓与泡沫贴合（先解决大面积方块感和岸线错位）。
2. 棕榈树冠与树干（轮廓占屏大，且能形成热带识别点）。
3. 小屋屋顶/檐口、船壳、码头结构（替换盒状建筑/交通工具主形体）。
4. 作物、鱼、渔具与小型摆件（分别定义外轮廓，不以统一 primitives 拼装）。
5. 最后才微调 AO、粗糙度和色彩；若灰模不过，不进入材质精修。
